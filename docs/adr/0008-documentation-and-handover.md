# ADR 0008: Documentation and core handover

- Date: 2026-10-30. Phase: 08, Documentation and handover. Status: Implemented; formal human acceptance not recorded.
- Contributor: Codex. Related requirements: evaluator setup and demonstration; production follow-ups in [requirements](../requirements.md).
- Context: The core service is a single-process UI/API backed by migrated SQLite and synthetic seed data. Earlier README material was too long for the user’s requested overview and did not fully explain the direct Python option or the UI workflow. Optional model work is deferred.
- Decision: Keep the README organized around introduction, workflow, installation, functionality, methodology, and stack. Use concise diagrams and screenshots from a synthetic live run. Put the detailed API walkthrough and production follow-ups in separate documents. Describe only the human workflow available in code; keep AI, real authentication, production readiness, and second-machine verification out of implemented claims. Do not make startup erase persistent data.
- Alternatives: Keep full evaluator and operational detail in one long README; rejected after the user requested a shorter, section-by-section guide. Add AI-on examples or production deployment instructions; rejected because those features are not implemented and AI work belongs to Phase 09.
- Consequences: The README supports same-host Windows setup through Compose or Python/uv and explains demo identities, configuration, request entry, reviewer decisions, and history. Supporting docs distinguish exercise defaults from policy and explain production work. Fresh-copy checks establish only the observed Windows/Docker Desktop environment; no second-machine or offline first-build claim follows.
- Limits/revisit: Human acceptance is not recorded. Hosted CI, second-machine setup, offline first image build, and model readiness, evaluation, and judge behavior remain unverified or deferred. The README’s resource advice is qualitative because minimum resources were not measured. Active work time was not recorded.
